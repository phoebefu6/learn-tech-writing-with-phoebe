Learn Tech Writing with Phoebe

Docs people actually use

You know the pain: the undocumented repo, the on-call engineer guessing at 2am, the wiki page nobody reads twice. This course is the fix - a practitioner's technical-writing method for data and AI teams, built from the same free sources Google trains its own engineers on. Across eight sessions you document one real pipeline end to end, and walk away with a documented system plus a repeatable method. Every session is 45 minutes live, with self-study depth for after class.

One project, eight sessions. Every session documents Pulse - a small CSV-to-metrics pipeline that ships in this repo at pulse/ with working code and zero documentation, on purpose. Session by session it gains a README, a how-to, reference pages, ADRs, a changelog, Vale linting in CI, and an edited v1.0 doc set you'd be proud to inherit. Honest about scope: certificates and the facilitated in-class exercises stay with the free official sources, starting with Google's technical writing courses.
